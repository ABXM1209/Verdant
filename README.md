# Verdant
### Synopsis
A personal project where I'm developing an RPG using Godot as the primary game engine, with a C# backend (Entity Framework and SignalR) handling persistent and live game data.
### Genre and Description
Verdant is based on a play-by-post game I developed in the past, similar in some ways to tabletop games like Dungeons & Dragons. By turning this into a video game, I aim to learn the fundamentals of game development while sharpening my skills in backend architecture, API design, and managing the distinction between live and persistent data (e.g. tracking HP, skills, and other character stats).
